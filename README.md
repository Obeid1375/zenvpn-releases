# ZenVPN — Releases

ساخته‌شده برای [ZenVPN](https://github.com/Obeid1375/zenvpn-android) روی اندروید.

## نصب

از آخرین Release فایل مناسب معماری گوشی را دانلود کنید:

- `app-arm64-v8a-release.apk` — بیشتر گوشی‌های امروزی
- `app-armeabi-v7a-release.apk` — گوشی‌های قدیمی‌تر ۳۲ بیتی
- `app-universal-release.apk` — همهٔ معماری‌ها

نسخهٔ نصب‌شده می‌تواند از داخل برنامه (تنظیمات ← بروزرسانی) خودش نسخهٔ تازه را از همین ریلیزها پیدا، دانلود و نصب کند. متن هر Release همان تغییری است که در پنجرهٔ بروزرسانی دیده می‌شود.

APKها با کلید debug امضا می‌شوند؛ برای انتشار عمومی کلید اختصاصی لازم است.
